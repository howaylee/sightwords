# Grace 单词大冒险 🎯

一个专为小朋友设计的 **Sight Words（高频视觉单词）** 互动学习卡片应用，支持移动端和桌面端使用。

## ✨ 功能特点

| 功能 | 说明 |
|------|------|
| 📚 **5 个难度等级** | 覆盖 Pre-Primer 到 3rd Grade 共 220 个核心词汇 |
| 🔀 **随机洗牌** | 每次学习自动打乱顺序，避免记忆位置 |
| 👆 **点击翻转** | 点击卡片查看中文释义和例句 |
| 📊 **进度追踪** | 实时显示当前学习进度（进度条 + 计数器） |
| ⬅️➡️ **前后翻页** | 支持上一个/下一个按钮自由浏览 |
| 🔄 **循环复习** | 学完一轮后可重新打乱再练 |
| 📱 **响应式设计** | 适配手机、平板和电脑屏幕 |

## 📖 难度等级说明

| 等级 | 名称 | 词数 | 适用阶段 |
|------|------|------|----------|
| **Level 1** | Pre-Primer | 40 词 | 入门级，最基础的高频词 |
| **Level 2** | Primer | 52 词 | 基础级，常用动词和代词 |
| **Level 3** | 1st Grade | 41 词 | 一年级，扩展词汇量 |
| **Level 4** | 2nd Grade | 46 词 | 二年级，更多语法相关词 |
| **Level 5** | 3rd Grade | 41 词 | 三年级，进阶高频词 |

> 以上 220 个单词来自经典的 **Dolch Sight Words** 列表。

## 🎮 使用方法

1. **选择等级**：在顶部下拉菜单中选择适合的难度等级
2. **看单词**：卡片正面显示英文单词
3. **点击查看详情**：轻点/点击卡片，展开中文释义和双语例句
4. **切换单词**：使用底部「⬅️ 上一个」和「下一个 ➡️」按钮翻页
5. **循环复习**：学完所有单词后，可选择重新打乱顺序再练一次

## 🛠️ 技术实现

- **纯前端单文件**：`index.html` 一个文件包含所有功能，无需服务器
- **HTML + CSS + JavaScript**：无任何外部依赖（除 Google Fonts 字体）
- **Fisher-Yates 洗牌算法**：保证每次打乱完全随机
- **CSS 动画**：包含弹跳提示动画和平滑过渡效果
- **字体**：`Fredoka One`（英文标题）+ `Noto Sans SC`（中文界面）

```bash

open index.html

# 或者直接双击文件
```

也可以部署到任意静态托管服务（如 GitHub Pages、Vercel 等）。

## 🎨 界面预览

- **顶部**：标题 + 难度选择下拉框 + 进度计数
- **中部**：进度条 + 可交互的学习卡片
- **底部**：上/下一个控制按钮

卡片展示内容：
- **正面**：英文单词（大字体）+ 点击提示
- **背面（展开后）**：中文释义 + 英汉对照例句（每词 2 条）

## 📝 自定义扩展

如需修改单词数据或添加新等级，编辑 `index.html` 中 JavaScript 的 `db` 对象即可。每个词条格式如下：

```javascript
{
    w: "单词",           // 英文单词
    c: "中文释义",        // 中文含义
    s: [                  // 例句数组（支持多条）
        { en: "English sentence.", cn: "中文翻译。" },
        { en: "Another example.", cn: "另一个例句。" }
    ]
}
```
